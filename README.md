
# HR Employee Compensation and Workforce Analysis

An independently developed Microsoft Excel data analysis project examining employee compensation, departmental salary distribution and workforce composition.

---

## 1. Project Overview

This project explores employee compensation and workforce distribution across different departments and employment categories using Microsoft Excel.

The analysis focuses on identifying salary patterns, comparing compensation across employment statuses, examining departmental workforce distribution and evaluating employee recruitment trends.

The objective is to demonstrate how Excel functions and analytical techniques can be applied to structured workforce data to generate meaningful insights for organisational decision-making.

## 2. Dataset Overview

The dataset contains **741 employee records** across **21 departments**, covering hiring years from **2004 to 2019**.

### Dataset Summary

| Metric | Value |
|:---|---:|
| Total Employees | 741 |
| Number of Departments | 21 |
| Employment Categories | 4 |
| Hiring Year Range | 2004–2019 |

### Dataset Variables

- Employee Name
- Department
- Hire Date
- Hiring Year
- Employment Status
- Benefits
- Compensation (Salary)

## 3. Tools and Techniques

**Primary Tool:** Microsoft Excel

### Excel Functions Applied

| Function | Application |
|:---|:---|
| `SUM()` | Calculating total salary expenditure |
| `AVERAGE()` | Calculating average employee compensation |
| `MIN()` | Identifying minimum salary |
| `MAX()` | Identifying maximum salary |
| `COUNTIFS()` | Counting employees using multiple conditions |
| `SUMIFS()` | Calculating salary totals using multiple criteria |
| `AVERAGEIFS()` | Calculating average salaries across departments and employment categories |

## 4. Analysis and Business Questions

The project addresses the following analytical questions:

1. What is the total salary expenditure across all employee records?
2. What is the average employee salary?
3. What are the minimum and maximum recorded salaries?
4. How is the workforce distributed across employment categories?
5. How does total salary expenditure vary by employment status?
6. How does average compensation differ across employment categories?
7. How is salary expenditure distributed across departments and employment statuses?
8. Which departments have the highest and lowest employee headcounts?
9. How are employee hiring records distributed across different years?

## 5. Key Findings

### 5.1 Overall Compensation Analysis

| Metric | Result |
|:---|---:|
| Total Salary | 47,928,375 |
| Average Salary | 64,680.67 |
| Minimum Salary | 21,001 |
| Maximum Salary | 126,627 |

### 5.2 Employee Distribution by Employment Status

| Employment Status | Employees |
|:---|---:|
| Full-Time | 374 |
| Contract | 126 |
| Hourly | 121 |
| Half-Time | 120 |
| **Total** | **741** |

Full-Time employees represent the largest employment category, accounting for approximately **50.5%** of the workforce.

### 5.3 Salary Expenditure by Employment Status

| Employment Status | Total Salary |
|:---|---:|
| Full-Time | 34,544,280 |
| Contract | 6,635,909 |
| Half-Time | 3,040,565 |
| Hourly | 3,707,621 |

Full-Time employees account for the largest share of total recorded salary expenditure.

### 5.4 Departmental Workforce Distribution

The departments with the highest employee headcounts are:

| Department | Employees |
|:---|---:|
| Manufacturing | 151 |
| Quality Control | 94 |
| Account Management | 88 |
| Quality Assurance | 73 |
| Facilities/Engineering | 59 |

Manufacturing has the largest workforce representation in the dataset.

### 5.5 Employee Recruitment Trends

The hiring-year analysis shows that **2013 and 2016** recorded the highest employee recruitment counts, with **92 employees each**.

The dataset covers recruitment records between 2004 and 2019.
